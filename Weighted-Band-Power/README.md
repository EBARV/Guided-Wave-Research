# Weighted Bandpower (WBP)
This repository aims to implement Weighted Bandpower (WBP) as introduced in [this paper](https://www.sciencedirect.com/science/article/abs/pii/S0041624X2030069X). WBP enhances the quality of bandpower computation for defects with a relative thickness of less than 90 percent by applying a distance-dependent attenuation compensation weighting factor. The results of the methodology for a CFRP quasi-isotropic plate is demonstrated below.

**Note:** Please run Maincode_WBP_Probing_Erfan and put all other functions in the same folder
