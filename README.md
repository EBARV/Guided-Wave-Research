# LFM Separation using DFrFT
In the first project contained in the [LFM Separation](https://github.com/AntixK/PyTorch-VAE/blob/master/README.md#--results) folder, the implementation of the paper entitled [Separation of overlapping linear frequency modulated (LFM) signals using the fractional fourier transform](https://ieeexplore.ieee.org/document/5587414) which can freely be downloaded [here](https://www.researchgate.net/publication/47299958_Separation_of_Overlapping_Linear_Frequency_Modulated_LFM_Signals_Using_the_Fractional_Fourier_Transform) is carried out. Discrete Fractional Fourier Transfrom is used to separate overlapping singnals through the determination of optimal value of FrFT transformation.
